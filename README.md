# Bulk DR Checker - Vercel Fixed

This version includes `index.html`, `style.css`, and `app.js` at the repository root to avoid Vercel 404 issues.

## Required GitHub structure

Upload the CONTENTS of this folder to GitHub root:

- index.html
- style.css
- app.js
- package.json
- vercel.json
- api/check-dr.js

Do not upload this whole folder as a nested folder.

## Vercel settings

- Framework Preset: Other
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: leave empty or npm install

Then deploy.
